# Project Name: Team Task Manager (Full-Stack)

Description:
A full-stack web application that allows users to create tasks, manage them, and track their progress with authentication.

## Tech Stack:
Frontend: React (Vite), JavaScript, CSS  
Backend: Node.js, Express.js  
Database: MongoDB Atlas  
Authentication: JWT  

## Features:
- User Signup & Login
- Create Tasks
- View Tasks
- Mark Task as Done
- MongoDB Storage
- Fully Deployed
